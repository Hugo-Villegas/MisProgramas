# MisProgramas

Colección de programas HTML de un solo archivo, sin instalación ni compilación. Se abren directamente en el navegador.

| Archivo | Descripción |
|---|---|
| `Ruta_de_Confiabilidad.html` | Curso gamificado "Ruta de Confiabilidad" (12 semanas, basado en el MGM de Parra y Crespo). Incluye quiz y herramientas: MES, CTR/MCR, AHP, Weibull, reemplazo por edad y costo de ciclo de vida (Woodward). Guarda el progreso en el navegador (localStorage). |
| `SimBloques_1.html` | SimBloques: simulador de diagramas de bloques de confiabilidad (RBD). |
| `Toolkit_Confiabilidad.html` | Toolkit de Confiabilidad IPM: herramientas de análisis de confiabilidad (incluye Crow-AMSAA) en un solo archivo. |
| `Taller_M340.html` | Taller de entrenamiento y simulador del PLC Modicon M340 / Control Expert. |

La carpeta `documentos/` contiene manuales de apoyo (por ejemplo, `Manual_Crow-AMSAA_tiempos_2.docx`).

## Cómo usarlos

1. Descarga el repositorio o clónalo: `git clone https://github.com/<usuario>/MisProgramas.git`
2. Abre el archivo `.html` deseado con doble clic en cualquier navegador moderno.

Nota: usan Google Fonts, por lo que se ven mejor con conexión a internet, pero funcionan sin ella.

## GitHub Pages (opcional)

Si el repositorio es público, puedes publicarlos en línea desde *Settings → Pages* (rama `main`, carpeta raíz).
