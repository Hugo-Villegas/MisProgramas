Cómo crear tu token de GitHub (una sola vez)

Opción recomendada — token «fine-grained»:

  1. En github.com: foto de perfil → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Ponle un nombre (ej. «Subir desde navegador») y una expiración (ej. 90 días).
  3. Repository access: «All repositories», o solo los repositorios que quieras usar.
  4. Permissions → Repository permissions: Contents = Read and write. Si quieres crear repositorios desde esta herramienta, agrega Administration = Read and write (y usa «All repositories»).
  5. Genera el token y cópialo de inmediato (empieza con github_pat_). GitHub no lo vuelve a mostrar.

Alternativa — token clásico: Tokens (classic) → Generate new token → marca el alcance repo. Es más simple, pero da acceso amplio a todos tus repositorios.

Si un repositorio existente aparece como «no encontrado», casi siempre es porque el token fine-grained no incluye ese repositorio o le falta el permiso Contents.

Se suben como máximo 100 MB por archivo (límite de GitHub). Los archivos idénticos a los que ya están en el repositorio no se vuelven a subir.
